apt.mlops.ninja

The Debian/Ubuntu package repository for mlnja tools. Ubuntu 22.04 LTS and newer, amd64 and arm64.

Add the repository

sudo curl -fsSLo /etc/apt/keyrings/mlops-ninja.asc https://apt.mlops.ninja/key.asc
echo "deb [signed-by=/etc/apt/keyrings/mlops-ninja.asc] https://apt.mlops.ninja stable main" \
  | sudo tee /etc/apt/sources.list.d/mlops-ninja.list
sudo apt update

Packages

  • fghj — sudo apt install fghj

After that, sudo apt upgrade keeps them up to date.
